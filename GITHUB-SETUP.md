# Put PSAT Path on GitHub

**Website name:** PSAT Path

**Repository name:** `psat-path`

**Description to copy:** A calm, interactive PSAT skills workbook with worked solutions, optional 1.5x module timers, progress tracking, and a study calendar.

## Simple steps — no coding needed

1. Download `psat-path-github.zip`. Double-click it to unzip it.
2. Sign in at [GitHub](https://github.com). Click **+** at the top right, then **New repository**.
3. Enter **psat-path** as the repository name. Paste the description above.
4. Choose **Public** for the simplest free GitHub Pages setup. The workbook code will be public; your typed answers stay in your own browser. Click **Create repository**.
5. Click **uploading an existing file**. If the repository already has files, click **Add file → Upload files** instead.
6. Open the unzipped folder. Drag **the files inside it**, not the ZIP or outer folder, into GitHub. You should see `index.html`, `style.css`, `app.js`, `content.js`, `icon.svg`, `README.md`, and this guide. If `.nojekyll` is hidden on your computer, it is fine to leave that empty file out for this plain static site.
7. Click **Commit changes**.
8. Click **Settings → Pages** in your repository.
9. Under **Build and deployment**, select **Deploy from a branch**. Choose **main** and **/ (root)**, then click **Save**.
10. Wait for GitHub to finish publishing. Refresh the Pages settings and click **Visit site**. If you used the signed-in account `adhayes1906-coder` and the repository name `psat-path`, the address will be `https://adhayes1906-coder.github.io/psat-path/` after successful publication.

The address above is the expected address, not proof of deployment. GitHub's Pages settings show the actual live address.

Official help: [Creating a GitHub Pages site](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## Try the demo

Add `?demo=1` to your live address. For example: `https://adhayes1906-coder.github.io/psat-path/?demo=1`.

Demo mode has sample answers, completed sessions, and planned dates. It uses separate browser storage and does not change your own workbook.

## Use your workbook

1. Open **Skills workbook** and choose a session.
2. Write your answers in **Questions**.
3. Open **Answers & solutions**, compare your work, and select **Got it** or **Revisit**.
4. Add a reflection and select **Complete session**.
5. Open **Study calendar** to choose a start date and a 2-day or 3-day weekly plan.

Timers start **off**. In the workbook, select a module, turn its timer **on**, and press **Start**. You can pause, reset, or turn it off.

| PSAT module | Standard | With 50% extra time |
| --- | --- | --- |
| Reading & Writing 1 | 32:00 | 48:00 |
| Reading & Writing 2 | 32:00 | 48:00 |
| Math 1 | 35:00 | 52:30 |
| Math 2 | 35:00 | 52:30 |

These are full module limits. The workbook's skill sessions are shorter than full test modules. The timer never submits answers. Practice settings do not establish official testing accommodations.

Timing source: [College Board PSAT/NMSQT structure](https://satsuite.collegeboard.org/in-school-assessments/whats-on-the-test/psat-nmsqt/structure).

## Save or move progress

Progress saves automatically in the same browser on the same device. In **My progress** or **How it works**, select **Export backup**. On another device, open the site and select **Import backup**. Importing replaces that browser's existing workbook data after confirmation. Different website addresses, including the demo hosting address and GitHub Pages, keep separate progress; use a backup to transfer it.

## Update the website later

Open the repository, choose **Add file → Upload files**, and upload replacement website files with the same names. Commit the changes. GitHub Pages will publish the update. Existing browser progress is preserved unless you clear browser data or change the storage format in code.
