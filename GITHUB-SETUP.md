# Put PSAT Path on GitHub

**Website name:** PSAT Path

**Repository name:** `psat-path`

**Description to copy:** An interactive PSAT/SAT study path with 120 sessions, five original practice exams, automatic grading, targeted practice plans, worked equations, optional 1.5x timers, and a study calendar.

## Simple steps — no coding needed

1. Download `psat-path-github.zip`. Double-click it to unzip it.
2. Sign in at [GitHub](https://github.com). Click **+** at the top right, then **New repository**.
3. Enter **psat-path** as the repository name. Paste the description above.
4. Choose **Public** for the simplest free GitHub Pages setup. The workbook code will be public; your typed answers stay in your own browser. Click **Create repository**.
5. Click **uploading an existing file**. If the repository already has files, click **Add file → Upload files** instead.
6. Open the unzipped folder. Drag **the files inside it**, not the ZIP or outer folder, into GitHub. You should see `index.html`, `style.css`, `app.js`, `content.js`, `sat-bank.js`, `sat-path.js`, `sat-path.css`, `reading-tips.js`, `vocabulary-data.js`, `vocabulary.js`, `vocabulary.css`, `icon.svg`, `README.md`, and this guide. If `.nojekyll` is hidden on your computer, it is fine to leave that empty file out for this plain static site.
7. Click **Commit changes**.
8. Click **Settings → Pages** in your repository.
9. Under **Build and deployment**, select **Deploy from a branch**. Choose **main** and **/ (root)**, then click **Save**.
10. Wait for GitHub to finish publishing. Refresh the Pages settings and click **Visit site**. If you used the signed-in account `adhayes1906-coder` and the repository name `psat-path`, the address will be `https://adhayes1906-coder.github.io/psat-path/` after successful publication.

The address above is the expected address, not proof of deployment. GitHub's Pages settings show the actual live address.

Official help: [Creating a GitHub Pages site](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## Try the demo

Add `?demo=1` to your live address. For example: `https://adhayes1906-coder.github.io/psat-path/?demo=1`.

Demo mode has sample answers, completed sessions, and planned dates. It uses separate browser storage and does not change your own workbook.

## Use your workbook

1. Open **Skills workbook** and choose a session.
2. Choose one option for each practice question in **Questions**. Use × to cross out an option if helpful.
3. Open **Answers & solutions**, see automatically checked answers and compare your work with the equations and explanations.
4. Add a reflection and select **Complete session**.
5. Open **Study calendar** to choose a start date and a 2-day or 3-day weekly plan.

Timers start **off**. In the workbook, select a module, turn its timer **on**, and press **Start**. You can pause, reset, or turn it off.

| PSAT module | Standard | With 50% extra time |
| --- | --- | --- |
| Reading & Writing 1 | 32:00 | 48:00 |
| Reading & Writing 2 | 32:00 | 48:00 |
| Math 1 | 35:00 | 52:30 |
| Math 2 | 35:00 | 52:30 |

These are full module limits. The workbook's skill sessions are shorter than full test modules. The workbook timer never submits answers. In a full practice exam, a module locks when its running timer reaches zero; you choose when to continue or submit. Practice settings do not establish official testing accommodations.

Timing source: [College Board PSAT/NMSQT structure](https://satsuite.collegeboard.org/in-school-assessments/whats-on-the-test/psat-nmsqt/structure).

## Follow the five-round SAT path

1. Choose **Five-round SAT path** in the menu.
2. Complete the original 24 workbook sessions, including the mixed review sessions, to unlock **Exam 1**.
3. Answer the 98 questions across four modules. Finish each module to continue; earlier modules lock. Take the 10-minute break before Math. Timers start off.
4. Submit the exam. See overall, Reading & Writing, and Math correct totals and percentages, plus solutions and a skill breakdown.
5. Optionally enter section scores from a separate official Bluebook exam. These fields accept official scores; the website does not estimate an SAT scaled score.
6. Open the next 24 sessions, created automatically from the missed and unanswered skills. Schedule them from that round’s page.
7. Repeat through round 5. The path ends at **120 sessions and five exams**.

Each follow-up session has four multiple-choice questions, explanations with math equations, learning links, and multiple-choice tips. Exam forms are original, fixed, nonadaptive practice with repeated question families and different values/scenarios. They match SAT question counts and passage-length limits but are not official or calibrated SAT tests. All Math items here use multiple choice; the actual SAT also includes student-produced answers. Use official Bluebook practice for an official practice score.

**Demo:** add `?demo=1#sat-path` to the website address. It shows a hypothetical first exam result and the next targeted plan. Choose **Preview a full exam** to explore testing without changing real progress.

## Save or move progress

Workbook and five-round progress save automatically in the same browser on the same device. In **My progress** or **How it works**, select **Export backup**. On another device, open the site and select **Import backup**. Importing replaces that browser's existing workbook data after confirmation. Different website addresses, including the demo hosting address and GitHub Pages, keep separate progress; use a backup to transfer it.

## Update the website later

Open the repository, choose **Add file → Upload files**, and upload replacement website files with the same names. Commit the changes. GitHub Pages will publish the update. Existing browser progress is preserved unless you clear browser data or change the storage format in code.


## Reading quick tips

Select **Reading quick tips** in the navigation menu, or open the tab with the same name inside a workbook or targeted practice session. Expand a question type for its strategy, reveal the example solution, and use the short checklist. The comparison panel explains what matches SAT format and what remains skill practice. Official sample questions, the Student Question Bank, and Bluebook links are included.


## Vocabulary flashcards

1. Select **SAT vocabulary** in the menu.
2. Choose a set of 10 words. Click a card to flip from the word to its definition and example sentence.
3. Select **Next word**. Optionally mark words **I know this** or **Practice again**.
4. After reviewing all 10 cards, choose **Take the 10-word quiz**. Answer all questions and select **Grade my quiz**.
5. Read the results, review missed words, retake the quiz, or continue to the next set.

Use **Hear word** for pronunciation, **Slower** for a slower reading, or **Hear example** for the sentence. Turn up your device volume. If audio cannot play, use **Dictionary pronunciation** under the buttons.

The library has 200 words selected from vocabulary questions in official released SAT Practice Tests 4–11, with 20 quizzes. Each card links to its source test and PDF page. Open “About these 200 SAT practice words” for the selection details. This is not an exhaustive list or a live-exam frequency ranking. Search can jump to any word. Progress saves in this browser, and backups include vocabulary progress. Matching words retain reviewed status and ratings from the earlier deck; earlier quiz scores appear separately in the history. Demo mode uses separate sample progress.
